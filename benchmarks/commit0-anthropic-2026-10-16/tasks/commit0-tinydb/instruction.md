# Implement the `tinydb` Python library

The repository in `/app` is the `tinydb` library with its implementation removed: in `/app/tinydb` function and method bodies were replaced with placeholders, while signatures, classes and docstrings remain. Implement the library so that it behaves as documented and its test suite passes.

- The tests are in `/app/tests` and run with `pytest` from `/app`. Do not modify the tests; the original test files are restored before grading.
- Write the implementation yourself. Do not download, copy or install the original library (or a fork of it) from the internet or any package index.
- Grading is the fraction of the test suite that passes.
