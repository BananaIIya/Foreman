## 方法与可复核性

- 12 个自制 JavaScript 任务覆盖 slug、CSV、区间合并、查询字符串、拓扑排序、TTL/LRU、并发限制、重试、深合并、金额分摊、HTTP byte ranges、事件订阅。公开规范、可见冒烟测试与隐藏断言均在实验前准备。
- A/B/C 使用同一公开任务、全新 Git 工作目录与 T3 线程；顺序轮换，3 次重复，并发数 2。B 使用 M3 既有 advisor 规划及可见验收机制，属于整个系统的比较。
- 隐藏断言通过独立的限时 Node 子进程评测，不发送给模型；参考实现通过、初始空实现失败、改写可见测试会被拒绝。这不是用于对抗恶意代理的隔离沙箱。
- 110 个工作目录均只修改 `solution.mjs`，没有新文件或额外 Git 提交。146 个原生会话 ID 唯一；110 条评分、用量和成本记录齐全。保存的候选实现位于 `solutions.json`，哈希见 `results.json`。
- 原生审计逐项对齐 146 个 CLI 会话的最终成本快照：完整会话 token 数与 T3 账本完全一致，110 条成本差为 0。主任务消息按官方单价及缓存 TTL 独立重算，供敏感性比较。
- 模型推理期间使用冻结的 v1 manifest；之后只有明确记录的评分勘误。`manifest.before-scoring-fix.json` 保留原协议，v2 manifest 对应最终评分器。
- API 单价依据 [Anthropic 官方定价](https://platform.claude.com/docs/en/about-claude/pricing)，核对日期 2026-10-13 UTC。原生会话总成本优先使用 CLI 报告值。

## 评分与账本勘误

评分器最初要求 retry 的非法参数必须抛 `TypeError`，但公开题目只要求拒绝非法数字，并未约束异常子类。合法的 `RangeError` 因此被误判。修正为接受 `Error` 后，对全部 110 份已保存答案统一重评；7 条结果改变：A-retry-1/2/3、B-retry-1/2/3、C-retry-3。原始通过数为 A 33/36、B 33/36、C 35/36。没有重新调用模型、改动候选答案或向模型提供隐藏反馈。原始结果、修正原因和评分哈希保留在 `summary.before-scoring-fix.json`、`results.json` 和 `scoring-correction.json`。

最初运行中的账本约 $13.617326，只覆盖主任务且缺少 1 小时缓存价格。验收发现后，修复了缓存 TTL 解析、价格计算、扫描缓存迁移和 SQLite 原生记录保留；随后等待 CLI 退出写入最终 `cost-state`，刷新得到 $24.757391。`originalCostUsd` 保留旧估算，最终数据全部使用完整会话成本。辅助调用可能延迟入账，所以运行时 $45 停止启动、单次 $1.50 取消阈值只是抽样守卫，不能视作平台硬限额。本次最高单次完整成本 $0.879589，总额在预算内。
