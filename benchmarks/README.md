# Benchmarks

Experiment archives for this fork's worker, advisor and lead + sidekick modes. They are records, not part of the product: nothing under this directory is built, shipped or run by CI.

Dollar figures are API-equivalent prices for subscription usage, computed from official per-token prices on the dates each report states. They are not billed amounts. Each report states its own scope and limits; read those before comparing numbers across reports, because accounting scope (main agent only, or full CLI session) differs between them.
